# 科创夜航第二轮动态体验升级设计

## 1. 目标

在保留“科创夜航·新生试航版”现有流程、视频风格和部门档案结构的前提下，解决放映仓内容不足、部分页面背景静止、标题拥挤、结果轨迹图过小、彩蛋素材重复等问题。

本轮不增加答题数量，不延长核心流程，不把新生固定定义到某个部门。动态效果用于解释内容、强化操作反馈和保持探索兴趣，不作为无目的装饰。

## 2. 视觉方向

- **视觉命题**：一次从陌生到愿意尝试的深空放映与信号探索。
- **主导系统**：本地高清动态背景、胶片放映、信号轨迹和真实部门照片。
- **记忆点**：三幕七部门自动放映、卡片重新定位转场、可读的五维行动星图。
- **页面节奏**：首页沉浸，破冰活跃，放映仓信息密集，过渡页短暂安静，行动站专注，报告页先电影化再进入安静阅读。
- **配色逻辑**：深黑蓝作为空间底色，青色表示信号和操作，黄色表示关键节点，部门档案继续使用各部门强调色。
- **克制规则**：一个页面只设置一个主动态系统，不同时叠加高强度视频、粒子、3D 球体和复杂卡片运动。

## 3. 科创放映仓

### 3.1 信息结构

保留三幕结构，将三张主图扩展为三幕七部门、共七个自动切换镜头：

1. **问题怎样出现**：项目部、科素部。
2. **事情怎样推进**：办公室、竞赛部、赛训部。
3. **成果怎样被看见**：宣传部、语培部。

每个镜头使用一个部门的真实照片，并展示：

- 部门名称；
- 与照片对应的工作场景标签；
- 新生可以从什么小任务开始；
- 当前幕和镜头进度。

### 3.2 文案格式

镜头文案统一使用：

```text
部门名称 / 工作场景
照片中正在发生的具体工作。
新生可以从一件简单任务开始。
```

文案必须以照片真实内容和现有部门资料为依据，不为照片添加无法确认的人物身份、赛事名称或成果数据。

### 3.3 交互

- 每个镜头停留约 3.5 秒后自动切换。
- 用户可点击镜头索引、左右按钮或在手机端横向滑动。
- 用户操作后暂停自动切换，约 1 秒后恢复。
- 顶部和底部胶片轨道使用七部门照片连续滚动。
- 继续保留暂停按钮和 `prefers-reduced-motion` 静态模式。

## 4. 破冰页面

“科创没有一扇必须先懂的门”采用 `404 Planet` 的空间球体氛围和 `Orbis Cards` 的三卡层次原则，形成原创的三张信号档案：

- 默认状态下三张卡片具有前后景深和轻微漂移。
- 点击一张卡片后，该卡片移动到主要阅读位置，另外两张退后。
- 使用 `Nimbus Ops` 式信号锁定反馈：扫描线、局部光圈和短暂状态文字。
- 手机端改为纵向卡组，保证三张卡片都可见且不依赖悬停。
- 背景与卡片运动保持低速，文字对比度不低于 WCAG AA。

## 5. 关键转场页

“刚才看到的是别人的故事”页面使用 `cosmic drift` 动态背景，并提取 `Relocation Card` 的空间连续性：

- 放映仓最后一帧缩小并向背景退去。
- 一束信号从画面远处移动到用户位置。
- 标题分两段出现，避免同时挤在首屏。
- 标题字距统一为 `0`，桌面端行高不低于 `1.02`，手机端行高不低于 `1.08`。
- 页面只承担 3–5 秒的情绪和流程转换，不增加新的阅读任务。

## 6. 五站行动页面

保留现有五站视频背景和题目结构，不再增加额外背景层。重点增加点击反馈：

- 选择选项时出现信号锁定光圈和路径亮起。
- 提交后按钮、反馈文字和进度线形成连续状态变化。
- 不依赖颜色单独表达已选择状态。
- 所有反馈在 150–500 毫秒内完成，不延长答题等待时间。

## 7. 试航报告

### 7.1 五维行动星图

当前分数通常在 20%–40%，不能直接把原始百分比作为半径。新图形采用相对映射：

1. 原始百分比仍在维度列表中如实展示。
2. 星图只负责展示五项信号之间的相对关系。
3. 当前最高维度映射到外圈附近，其他维度按与最高值的比例展开。
4. 设置最小可视半径，避免所有节点堆积在中心。
5. 网格从四层减少为三层，增加节点、连线和标签的可读面积。
6. 星图旁明确说明“图形展示相对航迹，百分比为原始记录”。

### 7.2 页面背景

- 报告首屏使用 `background 5` 或最终选定的独立低速视频。
- 视频只覆盖报告首屏，后续解释、方向和部门入口使用安静的深色表面。
- 首屏设置足够暗的遮罩，星图、标题和按钮不与背景竞争。
- 星图节点可轻微脉冲，指针靠近时显示维度名称和原始百分比。

## 8. 彩蛋

- 不再复用科创放映仓的 `future-reply` 视频。
- 使用 `liquid motion` 作为独立背景，表达信号变化、偏航和重新开始。
- 标题字距设为 `0`，行高提高，限制每行字数。
- 正文控制为 3–4 个视觉行，并与按钮保持明确间距。
- 添加一个可被鼠标或手指发现的隐藏信号点；触发后显示一句额外信息，但不阻挡返回报告。
- 减少动态模式下提供静态背景和直接显示的隐藏信息入口。

## 9. 全站文字疏密检查

本轮统一检查首页、破冰、放映仓、过渡页、五站、报告和彩蛋：

- 中文展示标题不使用负字距。
- 紧凑大标题行高不低于 `1.02`，手机端不低于 `1.08`。
- 避免依靠强制 `<br>` 造成窄屏断行错位。
- 正文行高保持在 `1.6`–`1.9`。
- 标题、正文、按钮之间建立至少 16、24、32 像素三级间距。
- 390×844 和 412×915 视口不得出现文字重叠或按钮越界。

## 10. 素材分配

| 参考素材 | 用途 |
| --- | --- |
| Orbis Cards | 三张误会卡片的空间层次与展开逻辑 |
| 404 Planet | 破冰页面的深空球体氛围 |
| Relocation Card | 放映仓到行动试航的关键转场 |
| Reading Library | 报告说明和部门档案的信息层级参考 |
| Nimbus Ops | 卡片和选项点击后的信号锁定反馈 |
| cosmic drift | 关键转场页背景 |
| background 5 | 报告首屏候选背景 |
| liquid motion | 彩蛋独立背景 |
| motion background 14 | 协作或推进相关局部视觉候选，不与既有视频叠加 |
| aurora waves | 备用低速背景，用于替换不合适的行动站视频 |

参考素材仅提取运动规律、空间关系和信息层次，最终组件、颜色、布局和动效参数按科创夜航重新设计，不照搬参考作品的完整视觉标识。

## 11. 响应式和性能

- 为新视频同时准备桌面和手机版本，并提供 WebP 封面。
- 首屏视频应静音、循环、内联播放，并在无法播放时回退到封面。
- 非首屏媒体延迟加载，避免多个高清视频同时解码。
- 手机端同时运行的视频不超过一个。
- 支持 `prefers-reduced-motion`，关闭自动卡片漂移、轨迹脉冲和复杂转场。
- 交互目标不小于 44×44 像素。
- 不产生页面级横向滚动。

## 12. 验收标准

1. 放映仓展示七部门镜头，每张照片都能直接说明“正在做什么”。
2. 破冰页三卡点击、展开和手机端纵向布局正常。
3. 关键转场页背景动态且文字不拥挤。
4. 五维行动星图不再集中在中心两个内圈，最高维度接近外圈。
5. 报告页使用独立动态背景，正文区域保持可读。
6. 彩蛋使用与前面不同的视频，并能触发隐藏信号。
7. 390×844、412×915、1280×800、1440×900 四个视口通过布局回归。
8. 单元测试、ESLint、TypeScript 构建和 Playwright 响应式测试全部通过。
